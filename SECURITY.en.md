# Security policy

[简体中文](SECURITY.md) · English

Do not disclose vulnerabilities, exploit details, credentials, or private data in public issues, pull requests, or discussions.

## Private reports

If GitHub private vulnerability reporting is enabled for this repository, open [Security Advisories](https://github.com/tonyflux/pkp/security/advisories), select **Report a vulnerability**, and submit a private report. Include the affected version, reproduction steps, impact, and necessary redacted evidence; do not send real passwords, tokens, or unrelated private data. Please allow the maintainers time to investigate and fix the issue, and coordinate public disclosure.

**External prerequisite:** a repository administrator must enable private vulnerability reporting in GitHub repository settings for the report button to be available; this document does not assert that it is enabled. If the button is unavailable, do not disclose the vulnerability in a public issue instead; wait for the maintainers to provide an available private reporting channel.
