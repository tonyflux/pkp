## Current publication status

Checked against GitHub Releases on 2026-11-02:

- [v0.2.0](https://github.com/tonyflux/pkp/releases/tag/v0.2.0) is published (2026-11-01). It is not a draft or a prerelease, and it is the Latest release. It includes the eight assets named in the retained notes below: two installers, `update.json`, `update.json.sig`, `PKP-0.2.0-source.tar.gz`, `libmpv-sources.tar.gz`, `LICENSE`, and `SHA256SUMS`.
- [v0.1.0](https://github.com/tonyflux/pkp/releases/tag/v0.1.0) remains published. Its seven assets and proprietary terms are unchanged. Those installers were not built from the source in this repository.
- The second retained note below still says v0.2.0 “has not been published.” That sentence described the repository before the release existed. The licensing distinctions in the note still apply. The release description on the v0.2.0 GitHub page is the same pre-publication text and can only be updated by editing the release, which this documentation change does not do.
