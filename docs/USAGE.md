# 使用说明

简体中文 · [English](USAGE.en.md)

本文说明当前产品行为，不代表已有公开发行版本。安装状态与平台限制见[安装说明](INSTALL.md)。

## 账号与文件

使用自己的 PikPak 账号登录。默认显示扫码登录：打开 PikPak App 扫描二维码，在手机上确认后进入云盘；二维码过期后点击刷新。添加账号和重新登录也支持扫码，重新登录时必须在手机上选择对应账号。二维码包含临时授权信息，不要公开截图或转发。

若二维码倒计时结束时已有确认请求正在处理，界面会等待该请求的最终结果；成功后正常完成登录，未成功时再提示刷新。关闭登录界面或切换登录方式仍会取消当前流程。

可切换到「密码登录」；其中「记住账号密码」将密码保存到系统凭据存储，「自动登录」依赖它，二者默认勾选，可在登录前取消。扫码不需要输入或保存密码，也不会修改已有账号的记住密码设置。扫码获得的会话仍会保存在本机并通过 refresh token 续期；服务端撤销会话后需要重新授权，已有密码自动登录设置仍按原设置生效。

左下账号入口可添加、切换和管理账号；切换浏览账号不会停止其他账号已在运行的本地传输。账号之间不合并成一个云盘。退出并移除账号会清理对应本地会话和记录，不会注销 PikPak 账号，也不会删除其云端文件或撤销分享；云添加任务可能仍在服务端继续。

文件页支持文件夹浏览、类型筛选、搜索、星标、分享与预览。首次本地索引建立可能需要等待。创建分享后，获得链接或口令的人可能访问分享内容，请按实际需要设置并及时取消分享。

文件网格和筛选栏会按窗口的可用空间自动调整；窗口较矮时，工作区可滚动，播放栏保持可见。这不会修改系统显示缩放，也不会重置手动选择的侧栏或信息栏状态。

## 上传、下载与云添加

- 「新建」可上传文件、上传文件夹或新建云端文件夹，也可把本地文件拖入文件页。
- 文件的更多菜单或多选操作栏可「下载到电脑」；默认位置是系统下载目录，可在「设置 → 传输」修改。同名文件通过编号区分，不直接覆盖已有文件。
- 顶栏「云添加」可提交你有权使用的链接或种子；任务执行、可用性与配额取决于 PikPak 服务。
- 在「传输中心」查看进度并按任务支持的操作暂停、继续或重试。退出应用会停止本机传输，云端任务不一定随之取消。

### 从网页和本机打开

- 安装新版 PKP 后，可将其选为 `magnet:` 链接和 `.torrent` 文件的打开程序。网页点击磁力链、或在电脑上双击种子文件，会启动 PKP；已在运行时交给原窗口处理。
- 打开后进入「云添加」确认，不自动创建任务。磁力链会预填到链接页；种子在本机解析，可勾选要保存的文件，并确认当前账号和目标文件夹。这是添加到 PikPak 云盘，不是本机 BT 下载器。
- 未登录或应用锁定时，请先登录或解锁。已有未提交内容时，新请求在本次运行中排队；提交或清空当前链接、或「移除」当前种子后继续。关闭确认框会保留当前内容，但退出 PKP 不会把未提交请求持久化。
- macOS：把新版 `.app` 安装到「应用程序」后启动一次，使系统识别其关联。种子文件可在 Finder「显示简介 → 打开方式」选择 PKP，再点「全部更改」。磁力链由系统／浏览器当前协议处理程序决定；若已绑定其他软件，注册 PKP 不会强行抢占，需要改选 PKP。浏览器仍可能要求确认打开外部应用。
- Windows：运行新版安装程序后，在「设置 → 应用 → 默认应用」中为 `.torrent` 和 `MAGNET` 选择 PKP。安装与卸载只维护 PKP 的候选关联，不改写系统的用户默认选择。直接运行便携 `.exe` 不会注册文件关联。

## 播放与阅读

打开视频或音频进入内置播放器，可按文件与服务可用情况切换清晰度、选择字幕、继续上次进度，或移到独立播放窗口。文本、图片、PDF、DOCX 和 XLSX 等可在应用内预览。PPT/PPTX 无内置预览，仍归为文档并显示既有不支持预览界面，下载等操作不变。网络、账号权限、服务端限速和文件编码都会影响播放；播放器故障可能影响整个应用。

## 局域网共享

「局域网共享」默认关闭，每次启动 PKP 后需手动开启。先设置非空的独立共享密码，两次输入一致即可，无最小长度或复杂度要求；再创建本地目录或固定云盘账号下的共享空间，选择局域网网卡并确认开始。手机或其他电脑连接同一网络后，打开显示的地址或扫描二维码；二维码包含地址和电脑当前界面语言，不包含密码。首次扫码会继承电脑语言，访客手动选择过的语言优先；复制或输入普通地址时沿用访客已选语言或浏览器语言。系统防火墙需允许该连接，路由器的访客隔离可能阻止设备互访。不要配置公网端口转发。

只有一个可用网卡时会自动选中；多个网卡需自行选择。刷新网卡后保留仍可用的选择，原网卡消失时会重新检查；自动选择不会自动开启共享。

桌面端的影响说明按操作类型仅确认一次：勾选「我已了解授权范围和影响，同类操作不再提示」并成功执行后，本机会记住，重启或操作其他空间也不再重复弹框；取消或执行失败不会记为已确认。后续操作仍需你主动点击，不会自动开启共享或扩大权限。新建空间与设置／重置密码保留必要表单，但已确认过的同类说明不再要求反复勾选。

创建云盘空间时，先选择固定来源账号，再单击文件夹逐层进入；可用面包屑或返回上级按钮定位。点击「选择这个文件夹」后检查目录摘要和完整路径，再点击新建以授权该目录。选择云盘根目录会包含该账号全部文件。「更改目录」可重新浏览，取消更改保留原选择；换目录后仍需检查范围并提交，选择目录本身不会创建空间。未手工修改的空间名称会跟随目录更新。

目录选择器支持搜索所选来源账号整个云盘中的文件夹，按名称匹配并显示完整路径，最多返回 100 个结果；结果较多时请缩小关键词范围。搜索复用本地索引，索引未就绪时可清空搜索继续逐层浏览。点击搜索结果只定位到该目录，仍需点击「选择这个文件夹」并提交新建空间；清空搜索恢复原浏览位置，切换账号或关闭对话框会丢弃旧搜索结果。

目录选择和文件准备弹窗均使用单一内容滚动区，底部操作保持可见。长名称和路径摘要默认收起；点击目录摘要中的路径或用键盘回车可展开完整授权范围，再次操作可收起。

在共享空间的「空间设置 → 选择文件准备」可浏览授权范围并跨目录选择文件，选择准备原件或面向常见设备的兼容副本，确认后逐项加入准备任务。它不会创建同步关系、上传、删除或修改云盘文件；电脑主动准备不依赖访客准备权限，也不自动打开该权限。兼容准备以 H.264/AAC/MP4 为目标，原件已兼容时可能直接复用；HDR 或不支持的媒体可能失败，具体设备仍需验证。提交部分失败时可在列表内查看原因并重试。下载原件存放在电脑任务页面标明的目录；转换结果使用独立兼容缓存。

手机支持原件时默认直接播放，不因索引较大弹出准备确认，也不会自动生成副本。对索引超过 4 MiB 的单视频／单音轨 SDR MP4，可在播放器「更多 → 优化起播速度（无损）」中主动选择生成无损播放副本：只重新封装，不重新编码，原件和下载内容不变。首次占用额外磁盘，须等待完整准备和验证，完成后从准备页手动播放副本；从文件列表进入仍优先播放能直放的原件，已有副本可在文件详情中主动播放。取消优化保持原件播放器。多轨、内嵌字幕及 HDR 不使用此优化。

电脑端「局域网共享 → 存储与副本」可分别设置「准备原件保存目录」和「兼容与无损副本保存目录」。所选目录须已存在且可写；更改仅影响后续新分配的文件，旧原件和副本留在原处继续复用，不自动搬迁或删除。进行中的准备结束或取消后才能改目录，已分配的等待任务恢复时仍使用原路径。磁盘断开或目录被替换时暂停准备，不自动重建或改用其他位置；恢复原磁盘后须手动恢复任务。普通下载和同步继续使用各自设置。

文件选择器默认列表视图，可切换为网格查看云盘已有的图片／视频缩略图和电脑上已就绪的 JPEG、PNG、GIF 图片缩略图；无缩略图或格式、大小超出预览限制时显示类型图标。预览不会下载完整云端原件或发起准备任务。切换视图和浏览其他目录不会清除已选文件。

选择器分别标记已就绪的原件和面向常见设备的兼容准备；当前方式已就绪的文件不能重复选择。切换准备方式会保留选择，但提交时跳过该方式已就绪的项目。兼容状态只在能核对当前文件版本和结果时显示；无法确认时仍可选择并由电脑重新核验。

读取目录时显示与文件页一致的列表／网格骨架和加载指示。本次弹窗内会临时保留最近浏览的目录、缩略图及各视图滚动位置，返回上级再进入时直接复用；可点击「刷新」重新读取当前目录。关闭弹窗或切换共享空间后缓存清除。缓存仅用于浏览，确认准备时仍重新核验来源和权限。

文件浏览与已选文件共用一个滚动区；底部已选数量可跳转到已选列表，少量或大量选择都不会再出现相互嵌套的滚动条。

云盘空间仍可查看覆盖当前目录的已有云端下载或双向同步关系，点击「查看与管理同步」进入其原设置；这些关系不由文件准备创建或修改，符合账号、文件和版本核验的已完成原件可复用。已有同步关系仍按其自身设置运行。

网页支持添加到主屏幕，以独立窗口打开。登录页及共享空间首页提供「添加到主屏幕」说明，关闭提示卡后仍保留文字入口；已在独立窗口中打开时不再提示。iPhone / iPad 在 Safari 的「共享 → 添加到主屏幕」操作，出现「作为网页 App 打开」时保持开启；支持的系统可去掉 Safari 地址栏和工具栏，但不绕过系统全屏、方向锁及画中画限制。Android / 电脑可从浏览器菜单选择安装或添加快捷方式，当前 HTTP 局域网地址不保证浏览器提供完整安装。

主屏幕入口只保存当前电脑地址；电脑 IP 或端口变化后须重新扫码添加。首次进入独立窗口可能需要重新输入共享密码。连接中断时页面提供「重新连接」，以实时请求核验会话；停止共享、重置密码和空间授权变更仍按原规则撤销访问。不注册 Service Worker、不建立离线内容缓存，不将文件列表、视频、密码或授权响应存入离线存储；页面仍需电脑开启共享并处于同一局域网。离线冷启动不能加载本功能页面，HTTP 的明文传输风险也不会因添加到主屏幕而消失。

- 访客只能读取明确授权的目录，不能上传、删除或修改文件。本地目录共享排除同步内部的 `.pkp-sync` 目录及其内容，也不能将其或子目录选作共享根目录；其他隐藏文件仍可能被共享，应使用专用目录。符号链接和目录联接不提供访问。云盘空间固定来源账号和根目录，不随桌面切换账号而改变。
- 本地完整原件可直接下载。云文件优先复用已完成的桌面下载或同步原件：同步记录须对应相同来源账号、文件 ID 和当前云端版本，并校验本地实际内容，不仅凭同名或大小判断。没有可复用原件时仍需「准备到电脑」，完成后再点击「下载原件」传到当前设备；首次核验大文件可能需要等待。网页准备页集中显示阶段和进度，完成后仍需手动选择播放或下载，不会自动开始。新准备原件的目标目录显示在电脑端「存储与副本」，旧资源可能仍留在之前的目录，不向访客公开本地路径。
- 每个空间独立控制「允许准备文件」。启用后访客可消耗电脑的网络、磁盘和算力；相同请求复用准备任务，不会取消独立的桌面下载。访客不能创建或控制同步关系；暂停同步后仍可复用核验一致的已完成原件。停止共享、重置密码或停用空间不会暂停、恢复或取消同步，也不会删除已完成的同步原件；兼容副本仍使用独立缓存。
- 网页先检测实际编码和浏览器能力：优先原件直放，再考虑仅重新封装或转换音频，必要时生成最高 1080p、保持比例且不放大小视频的兼容副本。原件不会被覆盖，原件下载始终保留原始内容；重新封装不降低视频分辨率。兼容副本全部完成并验证后才可播放，不支持边转码边播。不支持的 HDR 转换、字幕或额外音轨会提示限制，可下载原件使用本地播放器。
- 访客文件页默认使用列表，文件行可直接发起播放或准备，「更多」中查看详情和下载原件；手机顶部选择共享空间，底部切换共享文件和电脑准备任务。登录时可用密码输入框右侧的眼睛按钮显示或隐藏密码。
- 文件列表优先显示云盘已有的图片／视频缩略图，即使原件尚未下载到电脑；没有云端封面时，已就绪的本地图片仍可生成最长边 256px 的缩略图，其他文件保留类型图标。缩略图按可见范围加载，最多 2 路并发、64 张页面内缓存；云端封面经电脑实时核验账号、目录范围及版本后转为受限 JPEG，带签名地址不向访客公开。封面失败退回图标，不下载完整云端原件或启动准备任务；刷新、切换目录或退出清除页面缓存。地址栏及键盘仅改变页面高度时不再回拉列表位置。
- 手机图片预览使用全屏查看器，同目录已加载且就绪的图片可用上一张／下一张、左右滑动或键盘方向键切换，显示当前序号；不会自动下载未准备的云盘原件或预读相邻完整图片。翻图重新核验文件和权限，长目录可返回列表加载更多。查看器和其他弹层打开时锁住背景列表，关闭后恢复原滚动位置。
- 点击播放、预览或查看详情后立即显示当前等待状态；文件核验与播放方式检查可「取消等待」并重新操作。取消等待只中止本次网页读取，不取消已经提交的准备任务。首次原件校验或媒体探测仍可能耗时，等待时不会虚构百分比；失败后解除按钮锁定，可重试。
- 播放前的系统解码能力补充查询最多等待 250ms，超时按精确编码的浏览器支持结果尝试播放，不自动转码。相同版本及本地文件身份的媒体信息可复用；首次复用云盘下载／同步原件仍需核对完整内容，磁盘或云端响应较慢时仍可能等待。
- 首次进入播放器时，画面中央显示加载动画，取得可用画面后隐藏；播放中数据不足时显示缓冲动画。画面帧重新推进时立即收起缓冲提示，不依赖浏览器再次触发播放事件；不支持画面帧回调的浏览器及音频按实际播放时间推进恢复，元数据或跳转位置变化不冒充恢复播放。暂停、浏览器要求再次点按或播放失败时显示对应状态，不虚构百分比。云盘分段请求可以批量核验已知目录链，但每次仍读取最新授权元数据；文件移动或撤权后不可继续借用旧路径。
- 云盘目录先显示前 100 条；接近列表底部会继续读取，也可点击「加载更多文件」。搜索会继续检索该目录剩余分页，完成前显示检索状态；网络失败可手动重试，不自动反复请求失败页。本地目录仍一次读取。浏览快照只保存在当前网页内，最多 12 个目录／20,000 条；返回目录先显示快照，再实时核验，当前可见页约每 30 秒复查。点击刷新从首屏重新读取。文件操作和实际内容请求始终重新核验授权与版本，不将浏览快照作为访问凭证。
- 慢速读取期间可直接选择其他目录或文件，旧读取会取消；已提交的准备等写操作仍防止重复执行。网页关闭或处于后台时暂停不必要的状态刷新，任务页按需更新；首次媒体探测、完整原件校验及云服务本身的等待仍无法省略。
- 「电脑准备」支持单条「删除记录」和「清空已结束记录」，清理当前空间已完成、失败或取消的记录；进行中或等待处理的任务需先取消。清理只影响当前访客会话的列表，刷新页面仍保留清理结果，不影响其他访客、桌面任务、原件或兼容副本；退出或会话失效后重新登录会重新显示共享任务历史。
- 电脑端「局域网共享 → 准备任务」也可单条删除或按「任务范围」清空已结束记录；选择「全部空间」时清理所有空间，包括已移除空间的旧记录。仅隐藏电脑端列表，重启后仍隐藏，不影响访客列表、源文件、已下载原件或兼容副本。进行中或等待处理的任务需先取消；再次发起相同准备或重试后，相关记录会重新显示。
- 电脑端准备任务采用紧凑列表；任务较多时可在列表内滚动。电脑与网页进度按实际读取结果平滑更新，有可计算总量时显示百分比；暂停和阶段变化立即显示，没有可用总量时不估算。
- 网页播放器使用紧凑两行播控栏：上行显示时间与进度，下行保留播放、前后 10 秒、倍速和全屏；窄屏的亮度、静音及画中画保留在「更多」，支持画中画时正常竖屏顶部另有快捷按钮。正常竖屏时播控栏放在视频下方并保持可见，不遮住画面；横屏或全屏时浮在画面内，可自动隐藏，单击画面唤回。手机进入全屏时请求浏览器横屏锁定；不支持或被系统方向限制时，仅将播放器页面横向展示，不改变系统方向，旋转后的手势、进度条和菜单仍按画面坐标操作。退出全屏释放本次方向锁，并恢复原布局、滚动位置及播放列表先前的展开状态，不重新加载视频。播放页始终隐藏共享主页的 header 和搜索栏。默认全屏保留自定义操作，Safari 地址栏可能仍显示；支持的设备可在「更多 → 系统全屏（Safari 控件）」主动切换为系统视频全屏以隐藏浏览器栏，此时使用 Safari 控件。返回键、Esc 或浏览器返回先退出全屏，之后再返回原目录，保留搜索与滚动位置。
- 移动端支持横向滑动预览进度、松手跳转；左半屏上下滑调画面亮度，右半屏上下滑调网页可控音量。亮度只遮暗当前视频，不改变系统屏幕亮度；不支持网页音量控制时提示使用设备音量键，不显示虚构百分比。单击显示／隐藏浮动控件，双击左右两侧后退／前进 10 秒，双击中央播放／暂停；保留按钮、进度条和亮度滑杆，不会手势也能操作。多指、取消和屏幕边缘手势不提交跳转。手机横竖屏均保留完整视频比例及安全区，横屏或全屏播放中可自动收起控件。「更多 → 播放手势」可查看说明。桌面快捷键：空格／K 播放暂停、左右方向键跳转、上下方向键调可用音量、M 静音、F 全屏；输入框和选择框保留原生按键操作。
- 滑动与前进／后退使用轻量半透明提示，反馈显示期间暂不叠加加载／缓冲浮层；反馈结束后，仅在仍等待数据时恢复缓冲提示，错误与点按播放提示优先。拖动进度条只预览位置并暂时暂停，松手单次跳转，目标画面就绪后恢复原播放状态；原本暂停的保持暂停，取消拖动不跳转。按钮、键盘及画面手势跳转同样等待目标就绪后继续，不在中间位置反复播放。
- 手机支持时可从竖屏顶部画中画快捷按钮或「更多 → 画中画」进入系统悬浮视频，再次选择或关闭系统小窗退出；使用当前视频，不重载来源或改变播放／暂停状态。从自定义页面全屏进入画中画会恢复页面布局。提供标准画中画接口时以实际归属判断进入／退出状态，仅旧版 Safari 使用视频呈现模式；回到页面或重新打开菜单时刷新状态，避免残留「退出画中画」。设备或浏览器不支持时隐藏入口；系统设置、网页权限或具体视频仍可能拒绝请求，不自动绕过限制。
- 播放器菜单统一图标尺寸与文字起点。播放手势、亮度、更多及倍速浮层支持点击外部空白关闭；浮层内部可阅读或调整。点视频关闭浮层只负责收起，不同时暂停或触发画面手势；原打开按钮和 Esc 仍可关闭。
- 播放器同目录列表先显示当前文件及首批内容，每次「加载更多文件」追加最多 50 项；已显示项目不在滑动中回收，所有文件仍可继续展开访问。
- 兼容与无损副本不设固定容量上限，按所选磁盘的实际剩余空间准备；仍保留至少 512 MiB 可用空间及转换收尾余量，空间不足时停止准备，不会为了新任务自动删除已有副本。「存储与副本」显示实际占用，空缓存显示「暂无兼容副本」并禁用清理；主动清理仍跳过正在读取或准备中的内容，不删除原件及其他下载结果。
- 停止共享或重置密码会撤销访客会话并中断当前下载、播放；停用空间会中断该空间的访问。已经取得的文件无法收回。仅由访客发起的准备可完成当前安全阶段，后续阶段等待重新确认；电脑主动发起或接管的准备继续运行。停用空间会挂起两者；需要立即结束时，在电脑端取消对应任务。
- 来源校验可能需要等待云端响应。因来源不可用而挂起的准备任务不会自动重试；确认账号、网络和授权目录恢复可用后，可在网页准备详情点击「重新准备」，重新确认后按当前来源和权限执行，或在电脑端「准备任务」中点击「恢复准备」。访客取消只撤销自己的等待，即使原文件暂不可用也可以取消；其他访客仍需此任务时不会中断他们的准备。停止共享、重置密码和停用空间仍会直接撤销访客访问。

**普通 HTTP 不加密密码和文件内容，仅适用于可信局域网。应用锁和关闭窗口驻留不会停止共享；请主动停止共享或退出 PKP。** 电脑睡眠、网络变化、源目录或账号不可用时，访问可能中断。网页支持简中、繁中、英语、日语和韩语。

## 文件夹同步与整理

「同步」可创建双向同步、本地备份到云端、云端下载到本地关系。先确认两端目录与模式，审阅扫描预览再执行。内容核对可能读取云端文件字节并消耗下载流量；同步不是实时服务，也不是系统级后台守护，仅在 PKP 进程运行时工作。

暂停同步不会因网络恢复自动解除。移除关系保留已完成的两端文件；遇到待确认操作应先按界面处理。同步、批量改名、清理和 AI 整理都有改变文件的能力，操作前备份重要内容，不能把「可撤销」当作完整备份。

AI 助手的本地规则与统计可在未配置模型时使用。连接模型或 TMDB 是可选项，使用你自己的服务地址与凭据；发送前阅读数据授权提示，执行前检查实际文件操作计划。AI 可能判断错误，模型费用由所选服务决定。详见[隐私说明](../PRIVACY.md)。

Gemini API：在「设置 → AI」的提供商预设中选择「Google Gemini」，从 [Google AI Studio](https://aistudio.google.com/api-keys) 创建自己的 API Key，保存后刷新模型目录并测试连接；助手内的连接弹窗也可选择该预设。设置页完整展示当前服务端返回的模型列表，不使用本地白名单，也不删除或改写 `models/` 等模型 ID 前缀；选择后按原始 ID 保存并发送请求。预设自带的模型名只是初始值，不保证当前账号可用；应以官方目录中的实际模型 ID 为准。目录可能包含当前账号无法调用或不支持聊天接口的型号，权限与配额仍需「测试连接」确认。保留手动输入和已保存的模型，不自动替换，也不逐个调用探测。请求通过 Google 官方 OpenAI 兼容接口 `https://generativelanguage.googleapis.com/v1beta/openai` 发送，API 配额与计费独立于 Google AI Pro／Ultra 订阅；不支持 Google 账号或订阅 OAuth 登录。

新入库提醒只在已有可处理的整理建议时出现，助手首页、导航角标和菜单栏都遵循此规则。没有建议的文件仍保持未处理，不会自动忽略或标记为已整理；索引或命名设置变化后会重新检查。后台检查不会自动请求模型。

## 设置与退出

未登录时也可从登录页的「隐私与安全」进入本机设置，关闭「发送匿名使用统计」；同一页面可切换到「关于与更新」，不需要先登录 PikPak。

「设置」可调整语言、外观、传输、应用自身的网络代理、隐私与安全等。代理设置不修改系统 VPN 或系统代理；macOS 12/13 的 WebView 图片加载不支持与应用相同的代理配置，仍可能直连。

macOS 关闭主窗口只是收起，菜单栏驻留和各账号后台传输仍可能继续；请使用「退出 PKP」或 `⌘Q` 真正退出。应用锁默认关闭，锁定不会停止已授权的后台传输与同步，也不会加密已下载文件或整个本地数据目录。
应用锁独立密码同样不要求最小长度或复杂组合，设置或更改时输入非空密码并重复确认即可。短密码更容易被猜中；两类密码仍保留原有输入大小上限及错误尝试限流。

反馈问题前请脱敏账号、文件名、路径、分享链接、令牌与 API Key，不要上传整个配置目录或原始日志。
