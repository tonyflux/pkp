# 使用说明

简体中文 · [English](USAGE.en.md)

本文说明当前产品行为，不代表已有公开发行版本。安装状态与平台限制见[安装说明](INSTALL.md)。

## 账号与文件

使用自己的 PikPak 账号登录。默认显示扫码登录：打开 PikPak App 扫描二维码，在手机上确认后进入云盘；二维码过期后点击刷新。添加账号和重新登录也支持扫码，重新登录时必须在手机上选择对应账号。二维码包含临时授权信息，不要公开截图或转发。

若二维码倒计时结束时已有确认请求正在处理，界面会等待该请求的最终结果；成功后正常完成登录，未成功时再提示刷新。关闭登录界面或切换登录方式仍会取消当前流程。

可切换到「密码登录」；其中「记住账号密码」将密码保存到系统凭据存储，「自动登录」依赖它，二者默认勾选，可在登录前取消。扫码不需要输入或保存密码，也不会修改已有账号的记住密码设置。扫码获得的会话仍会保存在本机并通过 refresh token 续期；服务端撤销会话后需要重新授权，已有密码自动登录设置仍按原设置生效。

左下账号入口可添加、切换和管理账号；切换浏览账号不会停止其他账号已在运行的本地传输。账号之间不合并成一个云盘。退出并移除账号会清理对应本地会话和记录，不会注销 PikPak 账号，也不会删除其云端文件或撤销分享；云添加任务可能仍在服务端继续。

文件页支持文件夹浏览、类型筛选、搜索、星标、分享与预览。首次本地索引建立可能需要等待。创建分享后，获得链接或口令的人可能访问分享内容，请按实际需要设置并及时取消分享。

文件网格和筛选栏会按窗口的可用空间自动调整；窗口较矮时，工作区可滚动，播放栏保持可见。这不会修改系统显示缩放，也不会重置手动选择的侧栏或信息栏状态。

## 上传、下载与云添加

- 「新建」可上传文件、上传文件夹或新建云端文件夹，也可把本地文件拖入文件页。
- 文件的更多菜单或多选操作栏可「下载到电脑」；默认位置是系统下载目录，可在「设置 → 传输」修改。同名文件通过编号区分，不直接覆盖已有文件。
- 顶栏「云添加」可提交你有权使用的链接或种子；任务执行、可用性与配额取决于 PikPak 服务。
- 在「传输中心」查看进度并按任务支持的操作暂停、继续或重试。退出应用会停止本机传输，云端任务不一定随之取消。

## 播放与阅读

打开视频或音频进入内置播放器，可按文件与服务可用情况切换清晰度、选择字幕、继续上次进度，或移到独立播放窗口。文本、图片、PDF、DOCX 和 XLSX 等可在应用内预览。PPT/PPTX 无内置预览，仍归为文档并显示既有不支持预览界面，下载等操作不变。网络、账号权限、服务端限速和文件编码都会影响播放；播放器故障可能影响整个应用。

## 文件夹同步与整理

「同步」可创建双向同步、本地备份到云端、云端下载到本地关系。先确认两端目录与模式，审阅扫描预览再执行。内容核对可能读取云端文件字节并消耗下载流量；同步不是实时服务，也不是系统级后台守护，仅在 PKP 进程运行时工作。

暂停同步不会因网络恢复自动解除。移除关系保留已完成的两端文件；遇到待确认操作应先按界面处理。同步、批量改名、清理和 AI 整理都有改变文件的能力，操作前备份重要内容，不能把「可撤销」当作完整备份。

AI 助手的本地规则与统计可在未配置模型时使用。连接模型或 TMDB 是可选项，使用你自己的服务地址与凭据；发送前阅读数据授权提示，执行前检查实际文件操作计划。AI 可能判断错误，模型费用由所选服务决定。详见[隐私说明](../PRIVACY.md)。

计划预览将 AI 复核与清理入口集中在同一操作区，并直接展开前几项文件及保留原因。「AI 复核整份计划」可复核所有候选组，包括已命中规则的项目；「问 AI 识别剩下的 N 组」仍只处理未确认组，以减少发送范围与用量。整份复核发送文件名模式及已有规则或 AI 识别结果，不发送路径、样本文件或 TMDB 返回的标题、年份；AI 不读取实际文件内容，只更新建议预览。手动改名和原有操作勾选会保留，但新建议移到回收站的项会重新取消勾选。对话中的复核结果会保存，重新打开计划仍可查看；执行仍须最后确认。

对话搜索结果提供两种独立操作：「整理命名」用于媒体归类、移动和改名；「清理展示的 N 项」只把当前展示的去重结果列入清理预览，不会重新扫描或自动判断哪些是广告。清理候选默认不勾选，可以逐项确认保留，或勾选后在最后确认中移到回收站；不支持永久删除，未勾选的项不会被清理。选择文件夹时，其全部内容会一并移到回收站，请先核对。生成这份清理预览不会额外请求模型。

历史对话仍可使用：已打开的整理计划提供「清理预览 · N 项」，包括全部「保持原样」的计划；只将该计划列出的文件加入清理候选，不会把自动推导的空源文件夹变成整目录删除。也可在旧消息中展开「搜索过程 → 查看本次结果」，直接清理这次搜索加载的结果。两种方式均无需重新提问，切换后默认不勾选，并保留返回原对话的入口；不会自动把旧整理计划改成删除计划。

本地索引未就绪而导致查询受阻时，可安全重试的最近一轮回复会显示等待提示、当前索引进度和「重试原问题」。索引未完成时按钮禁用，完成后启用；点击沿用原问题和原范围，仍按现有流程请求数据发送授权，无需重新输入。索引完成不会自动向模型发送请求。历史回复中保存的同类索引错误也可使用该入口。

Gemini API：在「设置 → AI」的提供商预设中选择「Google Gemini」，从 [Google AI Studio](https://aistudio.google.com/api-keys) 创建自己的 API Key，保存后刷新模型目录并测试连接；助手内的连接弹窗也可选择该预设。设置页完整展示当前服务端返回的模型列表，不使用本地白名单，也不删除或改写 `models/` 等模型 ID 前缀；选择后按原始 ID 保存并发送请求。预设自带的模型名只是初始值，不保证当前账号可用；应以官方目录中的实际模型 ID 为准。目录可能包含当前账号无法调用或不支持聊天接口的型号，权限与配额仍需「测试连接」确认。保留手动输入和已保存的模型，不自动替换，也不逐个调用探测。请求通过 Google 官方 OpenAI 兼容接口 `https://generativelanguage.googleapis.com/v1beta/openai` 发送，API 配额与计费独立于 Google AI Pro／Ultra 订阅；不支持 Google 账号或订阅 OAuth 登录。

新入库提醒只在已有可处理的整理建议时出现，助手首页、导航角标和菜单栏都遵循此规则。没有建议的文件仍保持未处理，不会自动忽略或标记为已整理；索引或命名设置变化后会重新检查。后台检查不会自动请求模型。

## 设置与退出

未登录时也可从登录页的「隐私与安全」进入本机设置，关闭「发送匿名使用统计」；同一页面可切换到「关于与更新」，不需要先登录 PikPak。

「设置」可调整语言、外观、传输、应用自身的网络代理、隐私与安全等。代理设置不修改系统 VPN 或系统代理；macOS 12/13 的 WebView 图片加载不支持与应用相同的代理配置，仍可能直连。

macOS 关闭主窗口只是收起，菜单栏驻留和各账号后台传输仍可能继续；请使用「退出 PKP」或 `⌘Q` 真正退出。应用锁默认关闭，锁定不会停止已授权的后台传输与同步，也不会加密已下载文件或整个本地数据目录。

反馈问题前请脱敏账号、文件名、路径、分享链接、令牌与 API Key，不要上传整个配置目录或原始日志。
